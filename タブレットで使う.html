Web教材をタブレットで使う（教師用）

このフォルダの HTML は、外部ライブラリなし・1ファイル完結の Web教材です。生徒は各自1台のタブレットでブラウザを開き、授業で指定された画面だけを操作します。投影は、設定が合っているかの見本に使います。

推奨ブラウザ：Chrome または Safari（最新に近いもの）。
画面はタッチ用（ボタン高さ 44 px 以上、100dvh、ノッチ余白）にしてあります。

1. フォルダごと配る

次の6本と index.html を、同じフォルダ名のままタブレットに入れます。

  • 第1時_熱運動とブラウン運動.html
  • 第2時_℃とK.html
  • 第3時_熱量と温度.html
  • 第4時_熱の授受.html
  • 第5時_状態変化の平台.html
  • 第6時_熱と仕事.html

配布例：USBメモリ、校内ファイルサーバ、Google Drive／OneDrive（フォルダごとダウンロード）、MDM で一括配置。

2. 開き方（2通り）

A. タブレット内のファイルから開く（オフライン可）

ファイルアプリで index.html をタップ → ブラウザで開く → その時間のリンクをタップ。

機種によっては「ファイルから開く」と「ホーム画面に追加」で挙動が違います。授業の前日に、1台で6本すべて開けるか必ず試してください。

B. 教室の Wi‑Fi ＋ 簡易 Web サーバ（同じ URL で全員が開く）

先生の PC で、このフォルダを置いたうえで PowerShell から：

python -m http.server 8791

先生 PC の IP アドレスを調べ、タブレットのブラウザで次のように開きます（IP は例）：

http://192.168.1.10:8791/index.html

全員が同じ Wi‑Fi にいる必要があります。ファイアウォールで 8791 を許可してください。

3. 授業での使い方（データ用）

  • 事前・事後・遅延の選択問題のときは、タブレットは伏せる（Web教材は開かない）。
  • 観察のあいだだけ開く。手順に書いた設定・回数だけ止め、自分の画面の数字をワークに写す。
  • 投影だけを見て写した人は、論文の方法に人数を書く。
  • 6時間のあいだ、HTML ファイルを更新しない（更新したら 画面ファイルの記録.txt を取り直す）。

4. 論文の「方法」に書く1文（例）

HTML/CSS/JavaScript のみで作った Web教材を、生徒が各自のタブレットのブラウザで開き、指定した操作だけを止めて温度・熱量・グラフを読んだ。

5. 事前チェック（第1時の前）

  1. 生徒代表のタブレット1台で、6本が開き、ボタンが押せる。
  2. 第3時：水5回・鉄5回で表とグラフが写せる。
  3. 第4時：設定1で開き、3設定とも「熱平衡成立」まで進む。
  4. 第5時：質量 100 g・10000 J 固定、氷2回・水95℃2回で止められる。
  5. 開けない台の人数をメモする（投影のみ）。
